# smeta — форма ввода кошториса (ESCORE)

Веб-форма для безопасного заполнения расчётного файла проекта (Кошторис / Економіка) в Google Sheets.

**Живой сайт:** https://escoreodessa.github.io/smeta/

## Зачем это

Проектанты и инженеры вносили оборудование прямо в Google-таблицу-шаблон и ломали её структуру (удаляли названия групп, столбцы и т.п.), из-за чего ломался и генератор КП. Эта форма — «защищённый ввод»: пользователь заполняет только разрешённые (жёлтые) ячейки и структуру сломать не может. Вся математика остаётся в самой таблице.

## Как это работает

1. **Проектант** нажимает «Створити проєкт» → форма копирует мастер-шаблон в папку `Проекти/<название>` на Google Drive.
2. Проектант и **инженер** открывают этот проект через форму (по списку из папки «Проекти» или по ссылке `?id=<fileId>`), заполняют свои поля и жмут «Зберегти» — всё пишется в **тот же живой файл** на Диске (новых копий не создаётся).
3. **Anna** дорабатывает расчёт прямо в таблице (цены первого блока, панели, формулы, ПДВ/Моделювання), проверяет начальство.
4. Ссылка на готовую таблицу идёт в существующий **генератор КП**.

Форма **зеркалит** мастер-шаблон: строки, столбцы, цвета и выпадающие списки читаются из файла на лету. Поэтому изменения структуры/формул/цен в шаблоне подхватываются автоматически.

## Что считается полем ввода

- **Жёлтая заливка `#FFF2CC`** (и близкие тёплые оттенки), если в ячейке нет формулы → поле ввода.
- Ячейка с формулой → расчёт, заблокирована (показывается результат).
- Каскад **A→B→C** (Група → Підгрупа → Найменування) на строках, где в столбце A есть проверка данных (выпадающий список). После выбора наименования цена подтягивается из Довідника в столбец G.
- Розрахунок монтажних робіт — клон вкладки, редактируется столбец C (+ любые жёлтые ячейки).

Источник каскада — вкладка «Довідник обладнання та цін»: A = группа, F = подгруппа, B = наименование, D = цена.

## Конфигурация

Всё в `index.html`, объект `CONFIG`:

- `CLIENT_ID` — OAuth-клиент «ESCORE Economics Form» (проект Google Cloud **ESCORE-Maps**).
- `TEMPLATE_ID` — id мастер-шаблона (при смене шаблона поменять здесь).
- `SCOPES` — `spreadsheets` + `drive` + `openid email`.
- `PARENT_FOLDER` — `Проекти` (папка на Drive, куда складываются проекты).
- `REFERENCE_SHEET` — `Довідник обладнання та цін`.
- `ANNA_EMAIL` — аккаунт с расширенным доступом (режим «розрахунок цін»).
- `KOSH` / `ROB` — имена вкладок и номера столбцов каскада/цены/ввода.

## Связанный Apps Script

В мастер-шаблоне есть привязанный скрипт **«Выбор оборудования»** — он делает каскад **в самой таблице** (onEdit) и хранит `EXCLUDED_ROW_RANGES` (строки ручного ввода, где каскад выключен). Функция `cleanExcludedRows()` (меню «СЕС ▸ Почистити ручні рядки») убирает «унаследованные» выпадающие списки со строк ручного ввода. **Важно:** при перестановке строк в разделах нужно обновить `EXCLUDED_ROW_RANGES` под новую раскладку и запустить чистку.

## Деплой

Статический сайт на GitHub Pages (ветка `main`, папка root). Чтобы обновить: залить новый `index.html` в репозиторий (Add file → Upload files → Commit) — Pages пересоберётся за ~1 минуту.

## Доступ

OAuth-приложение в проекте ESCORE-Maps пока в режиме **Testing** — заходить могут только добавленные тест-пользователи (до 100, по email в Google Cloud → Auth Platform → Audience). Для широкой команды приложение можно опубликовать (для «чувствительных» scope Google просит верификацию).

## Как добавить тест-пользователя (доступ к форме)

Добавить нового человека в форму можно за минуту, без правок кода:

Зайди в Google Cloud Console под аккаунтом, где лежит проект: console.cloud.google.com
Убедись, что вверху выбран проект ESCORE-Maps (если нет — кликни по названию проекта и выбери его).
В меню слева (или через поиск сверху набери «Auth Platform») открой Google Auth Platform → Audience. Прямая ссылка: https://console.cloud.google.com/auth/audience?project=escore-maps
Пролистай до раздела Test users и нажми + Add users.
Впиши email (по одному, после каждого — Enter, появится «чип»). Можно сразу несколько.
Нажми Save.

Всё — новый человек сможет заходить в форму. Пара нюансов:

Работает только пока статус вверху — Testing. Если там окажется «In production», лучше вернуть кнопкой Back to testing (production без верификации как раз ломает вход).
Лимит — до 100 тест-юзеров.
Добавляй именно тот Google-аккаунт (gmail), которым человек будет логиниться в форму.
Удалить кого-то — иконка корзины напротив адреса в списке.

## Зависимости

Только CDN: Google API client (`apis.google.com/js/api.js`) и Google Identity Services (`accounts.google.com/gsi/client`). Сборки нет — один `index.html`.
